Omarchy シェル向けの、開いているアプリのドックです。時計の左側にあるバーにポインターを置いたままにすると、その真下にアプリアイコンの列が降りてきます。ワークスペース番号の上ではそのワークスペースのウィンドウを、ゾーン内のそれ以外の場所ではフォーカス中のワークスペースのウィンドウを表示します。画面の左・右・下には Apple 風のエッジドックを任意で置けて、すべてのワークスペースで開いているアプリを一覧します。どちらのドックも、アプリのウィンドウ一覧と Quit / Force Quit を備えた同じ右クリックメニューを共有します。

## 機能

- **バー内のホバードック。** ウィジェット自体は場所を取らず、バーの左端から時計までのバー全面を監視します。バーに時計がない場合、ゾーンはバーの左 40% です。
- **ワークスペースごとのプレビュー。** ワークスペース番号にポインターを乗せるとそのワークスペースのアプリが表示され、番号に沿って動かすとドックがリアルタイムで切り替わります。ポインターが番号以外のバー上にある状態でドックを開いたままキーボードでワークスペースを切り替えると、新しいワークスペースに追従します。
- **エッジドック (任意)。** すべてのワークスペースの開いているウィンドウを、左・右・下の端に表示します。`autohide` はポインターが端に触れるとスライドして現れ、`pinned` は出したままにして領域を確保するため、タイル配置のウィンドウが場所を空けます。
- **アプリごとにアイコン 1 つ。** 同じアプリのウィンドウが複数ある場合は、個数バッジ付きの 1 つのアイコンを共有します。アイコンをクリックするとウィンドウの 1 つにフォーカスし、もう一度クリックするとそのアプリのウィンドウを順に切り替えます。
- **アクティブ表示とツールチップ。** フォーカス中のウィンドウを持つアプリにはアクセントラインが付きます。アイコンの上に 400 ms とどまると、名前とウィンドウ数が表示されます。
- **右クリックメニュー**にはアプリのウィンドウ一覧 (アクティブなものに印) と **Quit** が並びます。メニューを開いている間に **Alt** を押し続けると **Force Quit** に変わります。
- **あふれ処理。** 長い列はマウスホイールでスクロールでき、末尾を超えたアイコンは `+N` で個数を表示します。
- **アイコンはバーに追従。** アイコンサイズはバーの高さ x 1.08 に Icon size 設定の倍率を掛けた値なので、Omarchy の UI スケールに合わせて変わります。

## インストール

```bash
omarchy plugin add https://github.com/seunghan91/omarchy-glance-dock --enable
```

ウィジェットの既定のセクションは `left` です。バー内には何も描画しないため、セクション内の位置は関係ありません。それでも移動したい場合は次を実行します。

```bash
omarchy bar move io.github.seunghan91.glance-dock --section left
```

## アップデート

```bash
omarchy plugin update
```

`omarchy plugin update` はインストール済みのプラグインを取得し、diff を表示して fast-forward します。

## アンインストール

```bash
omarchy plugin remove io.github.seunghan91.glance-dock
```

## 設定

Omarchy バーのウィジェット設定から変更します。

| キー | 値 | 既定値 | 意味 |
|---|---|---|---|
| `iconScale` | `small`, `normal`, `large` | `normal` | バーの高さ x 1.08 に対して、アイコンを 0.85 倍、1 倍、1.2 倍にします。 |
| `hoverDelayMs` | 0 – 1000 (50 刻み) | `250` | ホバードックが開くまでに、ポインターがバー上で静止している必要のある時間です。 |
| `edgeDock` | `off`, `left`, `right`, `bottom` | `left` | エッジドックの位置です。`off` にするとバーのホバードックだけを使います。 |
| `edgeMode` | `autohide`, `pinned` | `autohide` | `autohide` はポインターが画面の端に触れるとエッジドックをスライドして表示し (150 ms)、ポインターが離れて 300 ms 後に隠します。`pinned` は常に表示し、幅を確保してタイル配置のウィンドウが場所を空けます。 |

## 使い方

- **ホバードックを開く:** ホバー遅延の時間、時計の左側のバー上のどこかにポインターを置きます。ワークスペース番号の上ではそのワークスペースのアプリが、ゾーン内のそれ以外の場所ではフォーカス中のワークスペースのアプリが表示されます。ポインターがゾーンまたはドックの上にある間はドックが開いたままで、両方から離れて 120 ms 後に閉じます。
- **ウィンドウにフォーカス:** アイコンを左クリックします。もう一度クリックすると、そのアプリの他のウィンドウを順に切り替えます。エッジドックからは、そのウィンドウのワークスペースにも切り替わります。
- **アイコンを右クリック**するとメニューが開きます。ウィンドウタイトルをクリックするとフォーカスし、**Quit** をクリックするとメニューに並んだウィンドウを閉じます。バードックではそのワークスペース上のアプリのウィンドウが、エッジドックではすべてのワークスペース上のウィンドウが対象です。
- **Force Quit:** メニューを開いた状態で **Alt** を押し続けると、Quit が Force Quit に変わります。Alt を離すと元に戻ります。
- **メニューを閉じる:** **Esc** を押すか、メニューの外をクリックします。

## Quit と Force Quit の仕組み

- **Quit** はアプリの各ウィンドウに閉じるよう要求します。キーボードでウィンドウを閉じるのと同じなので、アプリは未保存の作業について確認できます。
- **Force Quit** は `hyprctl clients -j` と `jq` で各ウィンドウのプロセス ID を調べ、**SIGKILL** を送ります。そのプロセスの未保存の作業は失われ、複数のウィンドウが 1 つのプロセスを共有している場合 (ブラウザーやターミナルでよくあります) は、すべて閉じます。

## 既知の制限

- 右クリックの *前* に Alt を押している状態は検出できないため、メニューは Quit として開きます。メニューが開いてから Alt を押してください。
- マルチモニター: メニューを開いている間、Hyprland は別のモニターでのクリックをメニューに渡さないため、そこをクリックしてもメニューは閉じません。**Esc** を押してください。
- メニューは全モニターを通じて同時に 1 つだけ開きます。1 つ開くともう 1 つは閉じます。

## 動作要件

- Quickshell ベースのシェルとプラグイン (バーウィジェット) に対応した Omarchy。
- Hyprland 0.56 (ウィンドウのフォーカスと終了に Lua ディスパッチャー構文 `hl.dsp.*` を使います)。
- `hyprctl` (Hyprland に同梱)、`jq` (Force Quit)、`bash` と `find` (アイコン検索)。いずれも標準的な Omarchy のインストールに含まれています。

## プライバシーと安全性

- ネットワークにはアクセスしません。外部コマンドは `hyprctl` (フォーカス、クローズ、カーソル位置、クライアント一覧)、XDG アイコンディレクトリと `/usr/share/pixmaps` のローカルスキャン、Force Quit 用の `kill -KILL` のみです。
- 設定ファイルへの書き込みや変更は行いません。pinned モードは、ドックの実行中に限り layer-shell の exclusive zone で画面領域を確保します。
- ウィンドウアドレスは、シェルコマンドに渡す前に 16 進数であることを検証します。
- Force Quit はウィンドウのプロセスに SIGKILL を送ります。上の説明を参照してください。
