Док открытых приложений для оболочки Omarchy. Задержите указатель на панели слева от часов, и сразу под ним опустится ряд значков приложений: над номером рабочего стола он показывает окна этого рабочего стола, в любом другом месте зоны — окна рабочего стола в фокусе. Дополнительный док в стиле Apple у левого, правого или нижнего края экрана перечисляет все открытые приложения на всех рабочих столах. У обоих доков общее контекстное меню, в котором перечислены окна приложения и пункты Quit / Force Quit.

## Возможности

- **Док при наведении на панель.** Виджет не занимает собственного места: он следит за всей поверхностью панели от левого края до часов. Если на панели нет часов, зона — левые 40% панели.
- **Просмотр по рабочим столам.** При наведении на номер рабочего стола показываются его приложения; при движении вдоль номеров док переключается на лету. Если указатель находится на панели вне номеров, то при переключении рабочего стола с клавиатуры, пока док открыт, он следует за новым рабочим столом.
- **Краевой док (необязательно).** Все открытые окна на всех рабочих столах у левого, правого или нижнего края. `autohide` выдвигает его, когда указатель касается края; `pinned` оставляет его на экране и резервирует под него место, так что тайловые окна сдвигаются.
- **Один значок на приложение.** Несколько окон одного приложения используют общий значок со счётчиком. Щелчок по значку переводит фокус на окно; повторный щелчок переключает по кругу окна этого приложения.
- **Маркер активного приложения и подсказки.** Приложение, которому принадлежит окно в фокусе, получает акцентную линию; если задержать указатель на значке на 400 мс, показываются название и число окон.
- **Контекстное меню** со списком окон приложения (активное отмечено), затем **Quit**. Удерживайте **Alt** при открытом меню, чтобы превратить его в **Force Quit**.
- **Обработка переполнения.** Длинные ряды прокручиваются колесом мыши и показывают счётчик `+N` для значков за пределами видимой части.
- **Значки следуют за панелью.** Размер значка равен высоте панели x 1.08, умноженной на параметр размера значков, поэтому он следует за масштабом интерфейса Omarchy.

## Установка

```bash
omarchy plugin add https://github.com/seunghan91/omarchy-glance-dock --enable
```

Виджет объявляет `left` секцией по умолчанию. На самой панели он ничего не рисует, поэтому его позиция внутри секции не имеет значения. Если всё же нужно его переместить:

```bash
omarchy bar move io.github.seunghan91.glance-dock --section left
```

## Обновление

```bash
omarchy plugin update
```

`omarchy plugin update` загружает установленные плагины, показывает diff и выполняет fast-forward.

## Удаление

```bash
omarchy plugin remove io.github.seunghan91.glance-dock
```

## Настройки

Меняются в настройках виджета на панели Omarchy.

```bash
omarchy bar set io.github.seunghan91.glance-dock edgeDock right
omarchy bar set io.github.seunghan91.glance-dock edgeMode pinned
omarchy bar set io.github.seunghan91.glance-dock hoverDelayMs 150 --json
```

| Ключ | Значения | По умолчанию | Назначение |
|---|---|---|---|
| `iconScale` | `small`, `normal`, `large` | `normal` | Масштабирует значки в 0.85, 1 или 1.2 раза поверх высоты панели x 1.08. |
| `hoverDelayMs` | 0 – 1000 (шаг 50) | `250` | Как долго указатель должен находиться на панели, прежде чем откроется док при наведении. |
| `edgeDock` | `off`, `left`, `right`, `bottom` | `left` | Где находится краевой док; `off` — использовать только док при наведении на панель. |
| `edgeMode` | `autohide`, `pinned` | `autohide` | `autohide` выдвигает краевой док, когда указатель касается края экрана (150 мс), и скрывает его через 300 мс после ухода указателя. `pinned` оставляет его видимым и резервирует его ширину, так что тайловые окна сдвигаются. |

## Использование

- **Открыть док при наведении:** задержите указатель в любом месте панели слева от часов на время задержки наведения. Над номером рабочего стола вы увидите его приложения, в остальной части зоны — приложения рабочего стола в фокусе. Док остаётся открытым, пока указатель находится в зоне или на доке, и закрывается через 120 мс после того, как указатель покинул и то и другое.
- **Перевести фокус на окно:** щёлкните значок левой кнопкой. Щёлкните ещё раз, чтобы переключиться по кругу между остальными окнами приложения. Из краевого дока это также переключает на рабочий стол окна.
- **Щёлкните значок правой кнопкой**, чтобы открыть меню: щелчок по заголовку окна переводит на него фокус, а **Quit** закрывает окна, перечисленные в меню. В доке на панели это окна приложения на данном рабочем столе, в краевом доке — на всех рабочих столах.
- **Force Quit:** при открытом меню удерживайте **Alt**, и Quit превратится в Force Quit. Отпустите Alt, чтобы вернуть прежний вид.
- **Закрыть меню:** нажмите **Esc** или щёлкните в любом месте вне меню.

## Как работают Quit и Force Quit

- **Quit** просит каждое окно приложения закрыться, так же как при закрытии с клавиатуры, поэтому приложения по-прежнему могут запросить подтверждение о несохранённой работе.
- **Force Quit** определяет ID процесса каждого окна через `hyprctl clients -j` и `jq` и посылает ему **SIGKILL**. Несохранённая работа в этом процессе теряется, а если несколько окон используют один процесс (обычное дело для браузеров и терминалов), закроются все они.

## Известные ограничения

- Alt, зажатый до щелчка правой кнопкой, не определяется, поэтому меню открывается как Quit. Вместо этого нажмите Alt после открытия меню.
- Несколько мониторов: щелчок в любом месте другого монитора тоже закрывает открытое меню, как в macOS.
- На всех мониторах одновременно открыто только одно меню; открытие нового закрывает другое.

## Требования

- Omarchy с оболочкой на базе Quickshell и поддержкой плагинов (виджеты панели).
- Hyprland 0.56 (фокус и закрытие окон используют синтаксис диспетчера Lua, `hl.dsp.*`).
- `hyprctl` (входит в Hyprland), `jq` (Force Quit), `bash` и `find` (поиск значков). Всё это есть в стандартной установке Omarchy.

## Конфиденциальность и безопасность

- Нет доступа к сети. Единственные внешние команды: `hyprctl` (фокус, закрытие, позиция курсора, список клиентов), локальное сканирование каталогов значков XDG и `/usr/share/pixmaps`, а также `kill -KILL` для Force Quit.
- Не записывает и не изменяет ваши файлы конфигурации. Режим pinned резервирует место на экране через эксклюзивную зону layer-shell только пока док запущен.
- Адреса окон проверяются как шестнадцатеричные значения, прежде чем попасть в команду оболочки.
- Force Quit посылает SIGKILL процессу окна; см. выше.
